## Símbolos usados

1. Σ — alfabeto
2. Σ* — todas as palavras possíveis sobre Σ, incluindo ε
3. ε — palavra vazia, de comprimento zero
4. ∅ — conjunto vazio
5. L — linguagem
6. G — gramática, G = (V, T, P, S)
7. → — produção
8. ⇒ — derivação
9. | — "ou", separando produções
10. aⁿ — n ocorrências do símbolo a
